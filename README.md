# Smart-Agriculture-QA ESP32 + DHT (อุณหภูมิ/ความชื้น) + YOLOv8 (นับผลไม้) -> PHP REST API + MySQL -> Flutter Dashboard ``` Smart-Agriculture-QA/ ├── hardware/ hardware.ino โค้ด ESP32 ├── ai_engine/ flask_server.py, fruit_detector.py, test_client.py, requirements.txt ├── backend/ db.php, smart_farm_db.sql, seed_test_data.sql, apache_alias.conf, api/ ├── mobile_app/ lib/main.dart, pubspec.yaml ├── docs/ ANSWERS_and_RESULTS.md คำตอบท้ายการทดลอง + ตารางบันทึกผล ├── setup_windows.bat ติดตั้งอัตโนมัติ (Windows) └── .gitignore ``` ## ลำดับการติดตั้ง (ทำตามนี้) ### 1) Backend (XAMPP) 1. ติดตั้ง XAMPP -> เปิด Control Panel -> Start **Apache** และ **MySQL** 2. รัน `setup_windows.bat` (คัดลอก backend ไป `C:\xampp\htdocs\smart_farm` ให้อัตโนมัติ) หรือคัดลอกเองแล้วตั้งชื่อ `smart_farm` หรือใช้ Alias ตาม `backend/apache_alias.conf` (ข้อ 1.6 ของโจทย์) 3. เปิด http://localhost/phpmyadmin -> Import `backend/smart_farm_db.sql` (แล้ว import `seed_test_data.sql` เพื่อมีข้อมูลทดสอบ) 4. ทดสอบ: http://localhost/smart_farm/api/get_latest.php ต้องขึ้น JSON `"status":"success"` ### 2) Flutter ``` cd mobile_app flutter create . # (setup_windows.bat ทำให้แล้ว) flutter pub get flutter run -d chrome ``` แก้ `kServerHost` บนสุดของ `lib/main.dart`: Chrome = `localhost`, Emulator = `10.0.2.2`, มือถือจริง = IP เครื่อง Android: เพิ่ม `android:usesCleartextTraffic="true"` ในแท็ก `` ของ `android/app/src/main/AndroidManifest.xml` ### 3) ESP32 - Arduino IDE เปิด `hardware/hardware.ino` ติดตั้งไลบรารี DHT sensor library (Adafruit) + ArduinoJson v7 - แก้ `ssid`, `password`, และ IP ใน `serverUrl` (ipconfig, ห้ามใช้ localhost) - วงจร: DATA -> GPIO 4 (เปลี่ยนที่ `DHTPIN`), VCC -> 3.3V, GND -> GND, R 10kΩ คร่อม DATA-VCC - ใช้ DHT22 ให้เปลี่ยน `DHTTYPE` เป็น `DHT22` ### 4) AI Engine - วาง `best.pt` ที่ `ai_engine/runs/detect/fruit_web_model/weights/best.pt` (หรือตั้ง `MODEL_PATH`) - `pip install -r requirements.txt` - กล้องเว็บแคมตรง: `python fruit_detector.py` (กด q ออก) - เซิร์ฟเวอร์รับภาพ: `python flask_server.py` แล้วทดสอบ `python test_client.py fruit.jpg` - ถ้าเครื่องไม่มี GPU โปรแกรมเลือก CPU ให้อัตโนมัติ ## ทดสอบ API ด้วย curl ``` curl -X POST http://localhost/smart_farm/api/store_telemetry.php -H "Content-Type: application/json" -d "{\"temperature\":28.5,\"humidity\":60}" curl -X POST http://localhost/smart_farm/api/store_telemetry.php -d "temperature=28.5&humidity=60" curl -X POST http://localhost/smart_farm/api/store_inventory.php -F apple=3 -F mango=2 -F orange=1 curl -w "\n%{time_total}s\n" http://localhost/smart_farm/api/get_latest.php ``` ## Git Workflow (ตอนที่ 5) ``` git init && git add . && git commit -m "init" git branch -M main git remote add origin https://github.com//Smart-Agriculture-QA.git git push -u origin main git checkout -b feature/hardware # แยก branch ต่อคน: feature/flutter-ui, feature/phpapi ... ``` เปิด Pull Request เข้า `main` ต้องมีเพื่อนอย่างน้อย 1 คน Review ก่อน Merge ## แก้ปัญหาเบื้องต้น | อาการ | วิธีแก้ | |---|---| | Flutter ขึ้นหน้า Flutter Demo | `lib/main.dart` ยังเป็นไฟล์เดิม ใช้ไฟล์ในโฟลเดอร์นี้ทับ | | Flutter ขีดแดงทั้งไฟล์ | รัน `flutter pub get` แล้ว Dart: Restart Analysis Server | | Dashboard "เชื่อมต่อ Server ไม่ได้" | เปิด URL get_latest.php ในเบราว์เซอร์ก่อน, เช็ก Apache, Firewall, `kServerHost` | | ESP32 ส่งไม่ได้ (HTTP -1) | ใช้ IP จริงไม่ใช่ localhost, WiFi วงเดียวกัน, Firewall เปิดพอร์ต 80 | | Apache ไม่ Start | พอร์ต 80 ถูกใช้ (Skype/IIS) | # Lap10 # Lap10 # Lap10
